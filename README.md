# vhybecheck — issues

Bug reports and feature requests for **[vhybecheck](https://vhybecheck.app)**, a
macOS menu bar app that shows how much of your AI subscriptions you have left
across Claude, GitHub Copilot, Cursor and ChatGPT.

This repository holds no code. It exists so that anyone using the app can file
a report without needing access to the private source repository.

- **[Email support@goldshorts.com](mailto:support@goldshorts.com)** for help with the app
- **[Report a bug](../../issues/new?template=bug_report.yml)**
- **[Request a feature](../../issues/new?template=feature_request.yml)**
- **[Browse known issues](../../issues)**

The app's **Report a bug** button fills most of a bug report in for you,
including the app version and your macOS version.

## What gets sent

The prefilled report contains the app version, your macOS version and
architecture, and for each provider: the plan name, whether credentials are
present, and the text of any current error.

It never includes your email address, account name, session cookies, API
tokens, or any usage figures. You can edit or delete any of it before posting —
nothing is submitted until you press **Create**.
